## สรุป

**ไม่มี candidate ที่ผ่านเกณฑ์** M0 (config production ต่อลีก) ดีที่สุดหรือเสมอทุก candidate ทั้งบน development และ final holdout ส่วนค่าที่ shrink มากขึ้นหรือ half-life สั้นลงแย่กว่า M0 อย่างมีนัยสำคัญ

การลด `priorStrength` ลงเหลือ 1 ทำให้โมเดลคมขึ้น (calibration slope 1.13 → 1.03, sharpness เทียบตลาด 0.85 → 0.93) และความเอียงไปทางทีมรองลดเกือบครึ่ง (3.4 → 1.9 จุด) แต่ Brier ของ AH และ log loss ของ 1X2 ไม่ดีขึ้น ความแบนจึงเป็นอาการ ไม่ใช่ต้นเหตุของการแพ้ตลาด โมเดลมีข้อมูลน้อยกว่าตลาดในทุก config ที่ทดลอง

สำหรับถ้วยยุโรป การให้น้ำหนัก cross-league มากกว่า 0.5 ดีกว่า production ชัดเจนบน holdout แต่ไม่ผ่านบน development ตามกฎที่ตั้งไว้ จึงยังไม่ผ่าน และต้องยืนยันด้วยข้อมูลใหม่

## 6. Root cause: ยืนยันแล้วกับยังเป็นสมมติฐาน

**ยืนยันด้วยข้อมูล**

1. ความเอียงไปทางทีมรองเกิดในตัวโมเดล ไม่ใช่ใน candidate selection เกิดซ้ำในข้อมูลย้อนหลัง 2 ฤดูกาล 19 ลีก (3.3 จุด) และในทุกลีก
2. ความเอียงโตตามขนาดแต้มต่อ (AH 0: 0 จุด, 1–1.5: 6.5 จุด) และใหญ่กว่าในทีมที่ข้อมูลน้อย
3. `priorStrength` ควบคุมความแบน: prior สูงทำให้แบนและเอียงมากขึ้น และแย่ลงอย่างมีนัยสำคัญ (prior 20) แต่ prior ต่ำกว่าค่า production ไม่ทำให้แม่นขึ้น
4. ช่องว่างกับตลาดไม่ได้อยู่ที่ prior หรือ half-life ทุก config แพ้ตลาดใกล้เคียงกัน ตลาดมีข้อมูลที่โมเดลไม่มี
5. ในถ้วยยุโรป ส่วน cup-only ของ mix คือส่วนที่แย่ที่สุด และทำให้เอียงมากที่สุด

**ยังไม่ยืนยัน**

- ถ้วยยุโรปควรใช้ cross-league มากขึ้น (ต้องทดสอบกับแมตช์ใหม่)
- ส่วนที่ live เอียงมากกว่าข้อมูลย้อนหลัง: อาจมาจากสัดส่วนถ้วยยุโรป (live 108 จาก 614 นัด เอียง 10–14 จุด) ต้นฤดูกาลที่ข้อมูลฤดูกาลใหม่น้อย หรือ Player Impact
- โมเดลขาดข้อมูลอะไรเมื่อเทียบตลาด (ผู้เล่น/ตัวจริง, ข่าว, แรงจูงใจ, การหมุนเวียน) งานนี้ไม่ได้วัด
