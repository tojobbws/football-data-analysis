# Hybrid AI v2.1: ผล replay แบบ dry-run

วันที่ 2026-11-16 · ADR 0021 · สคริปต์ `scripts/research/hybrid-v21-replay.ts` · ผลละเอียด `reports/hybrid-v21/`

ขอบเขต: ไม่เขียนฐานข้อมูล ไม่เผยแพร่อะไร ไม่แตะ prompt หรือ input ของ production และไม่อ่านผลการแข่ง ใช้ gpt-6-luna

## สิ่งที่เทียบ

ทั้งสองแบบใช้ input ที่เก็บไว้ชุดเดียวกัน และใช้ตัวเลือกตลาดเดิม (สร้างกลับจาก input ที่เก็บไว้)

- **control** = v2.0 แบบที่ production รันอยู่ คือ prompt v2.0, input เดิม, ถามซ้ำด้วยคำขอเดิมไม่มี feedback และใช้ guard ที่แก้เรื่องตัวคั่นหลักพันแล้ว
- **v21** = input ที่เพิ่มค่ารวมไว้ให้, prompt v2.1 และถามซ้ำพร้อม feedback ระบุจุดที่ผิด

ส่วนที่เหมือนกัน: ถาม 3 คำตอบ, ถามได้ไม่เกิน 2 ครั้งต่อคำตอบ, validator ตัวเดียวกัน และกติกาเสียงข้างมากเดียวกัน

**กลุ่มที่ทดสอบ**
- **G1:** 16 decisions ที่จบเป็น INVALID ใน production
- **G2:** 82 decisions ที่ผ่าน แต่ต้องถามซ้ำก่อนผ่าน

## คำตอบที่ผ่าน guard แต่ยังอาจเสี่ยงเรื่องความถูกต้อง

**วิธีนับ:** หาตัวเลขทศนิยมในข้อความของคำตอบที่ผ่าน ซึ่งมีค่าเท่ากับผลบวกหรือผลต่างของค่าใน input เดิม (คือหน้าตาเหมือน AI คำนวณเอง) และค่านั้นไม่ได้อยู่ใน input เดิมตรงๆ

**สุ่มอ่าน 8 ประโยคเพื่อดูว่าใช้ถูกบริบทไหม:** ทุกประโยคใช้ตัวเลขตรงกับความหมายของฟิลด์ เช่น *"Celta มีค่าเฉลี่ยประตูรวม 2.3 และ xG รวม 2.22 ใน 10 นัดล่าสุด"* และ *"สกอตแลนด์มีค่า xG รวมเฉลี่ย 3.04 ใน 4 นัดที่มีข้อมูล"*

**ความเสี่ยงที่เหลือ** (เป็นเรื่องการตีความ ไม่ใช่ตัวเลขผิด)
- บางประโยคยกค่าเฉลี่ยจากตัวอย่างนิดเดียว โดยไม่บอกจำนวนนัด เช่น *"เกมเหย้าของ Aalesund มีค่าเฉลี่ยประตูรวม 6.5"* ทั้งที่ input มีฟิลด์ `*_matches` บอกไว้
- ถ้าจะใช้จริง ควรเพิ่มคำสั่งว่า "บอกจำนวนนัดเมื่อยกค่าเฉลี่ย"

**ข้อจำกัดของการนับ:** นับเฉพาะเลขทศนิยม ผลต่างที่เป็นจำนวนเต็ม เช่น "ห่าง 16 แต้ม" ไม่ได้นับ แต่ใน v21 ค่านี้มีอยู่ใน `comparison.league_table` แล้ว

## สรุป

1. **v2.1 แก้ต้นเหตุได้จริง**
   - INVALID ใน G1 ลดจาก 7/16 (control) เหลือ 0/16
   - ใน input v2.0 attempt ที่ถูกตีตกลดจาก 34% เหลือ 0%
   - ทั้งหมดนี้ไม่ได้ผ่อน guard เลย ตัวเลขทุกตัวที่ผ่านยังอยู่ใน input
2. **ถามซ้ำพร้อม feedback ได้ผล:** 2/2 ผ่าน เทียบกับแบบไม่มี feedback ที่ผ่านแค่ 8% (G1) และ 69% (G2)
3. **ไม่พบว่าการเลือก pick เปลี่ยน:** การกระจายฝั่งที่เลือกและการตรงกับ live เท่ากับ control (58/82)
4. **ตัวเลขที่ดูเหมือนคำนวณเองแต่ผ่าน guard:** ทุกตัวคือค่า aggregate ที่เราคำนวณให้ ไม่มีตัวไหนผ่านเพราะบังเอิญ

## ถ้าจะใช้จริง (ยังไม่ได้ทำ รอคุณอนุมัติ)

1. `collectHybridInput` เรียก `withAggregatesV21` แล้วใช้ `HYBRID_PROMPT_VERSION_V21` กับ `HYBRID_SYSTEM_PROMPT_V21`
2. `askOnce` ใน `hybrid-job.ts` เปลี่ยนไปใช้ `createOpenAIHybridDeciderV21`: attempt 2 ส่ง `retryFeedbackV21(locateViolations(...))` ไปด้วย ส่วนจำนวนครั้งยังเท่าเดิม
3. (แนะนำ) เพิ่มคำสั่ง "บอกจำนวนนัดเมื่อยกค่าเฉลี่ย" ซึ่งจะทำให้กลายเป็น v2.1.1 และต้องรัน replay ใหม่
4. นับ pick ของ v2.1 แยกจาก v2.0 ด้วย `prompt_version` และต้องตัดสินว่าจะทำอย่างไรกับการทบทวน v2.0 ที่ 100 pick ตาม ADR 0020
5. แยกกันแต่ควรทำ: แก้ `isPersistentOpenAIError` ให้รู้จักข้อความ "no credits remaining"
