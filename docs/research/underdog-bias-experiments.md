# Underdog bias — การออกแบบการทดลอง (Phase 1–2)

วันที่ 2026-10-27 · baseline: [underdog-bias-baseline.md](underdog-bias-baseline.md) · ผล: [underdog-bias-results.md](underdog-bias-results.md)

เอกสารนี้เขียนและ commit พร้อมโค้ดก่อนอ่านผลการทดลอง กฎเลือกอยู่ในโค้ด (`selectCandidate` ใน `scripts/research/sharpness.ts`) ไม่ได้ปรับหลังเห็นผล

## คำถาม

โมเดลให้ทีมรองบนเส้น AH หลักสูงกว่าตลาด 6.6 จุด ขณะที่ผลจริงใกล้ตลาด การเปลี่ยนค่าใดค่าหนึ่งของ Dixon-Coles ทำให้ความน่าจะเป็นแม่นขึ้นเมื่อเทียบ M0 และเข้าใกล้ตลาดหรือไม่ และถ้าทำได้ ความเอียงไปทางทีมรองลดลงด้วยหรือไม่

## Walk-forward

- ลีกในประเทศ: ทุกลีกที่มีราคา PIN ใน `external_odds` (19 ลีกสำหรับ 1X2, 11 ลีกสำหรับ AH และ O/U 2.5)
- เริ่มวัดหลัง burn-in 365 วันนับจากแมตช์แรกของลีก
- ทุกการทำนาย fit จากแมตช์ที่เตะก่อน kickoff − 3 วัน และ refit ทุก 7 วัน (warm start) ราคาตลาดไม่ได้เป็น input ของโมเดล
- ทุก config ทำนายแมตช์ชุดเดียวกัน (มี test)
- ถ้วยยุโรป: walk-forward บนแมตช์ถ้วยทั้งหมด refit ทุก 14 วัน cup-only และ cross-league fit พร้อมกันแล้วผสมตามแต่ละน้ำหนัก

## Final holdout

- ลีกในประเทศ: 20% สุดท้ายของวันฟุตบอลที่มีราคา AH early จากวันนั้นไปทั้งหมดเป็น holdout ใช้ทุกตลาด
- ถ้วยยุโรป: 20% สุดท้ายของวันฟุตบอลที่มีแมตช์ถ้วย
- `selectCandidate` รับเฉพาะแถว development (`splitAt`) holdout จึงไม่ถูกใช้เลือก (มี test)
- หลังเลือกแล้ว holdout รายงานเฉพาะ M0, REF, ตัวที่เลือกของแต่ละการทดลอง และถ้าการทดลองไหนไม่มีตัวผ่าน จะรายงานตัวที่ดีที่สุดบน development เพื่อดูทิศทางเท่านั้น ไม่ถือว่าผ่าน

## เกณฑ์ (กำหนดก่อนรัน)

- **Primary:** Brier ของ AH เส้นหลัก บน fair target ที่ราคา early (ฝั่ง HOME; ฝั่ง AWAY เป็น complement จึงได้ค่าเดียวกัน)
- **Guard:** log loss ของ 1X2 ที่ราคา early
- **ผ่านบน development:** ดีกว่า M0 ใน primary ด้วย p ที่ปรับ Holm ข้าม candidate ของการทดลองเดียวกัน < 0.05 และไม่แย่กว่า M0 อย่างมีนัยสำคัญใน guard (ขอบล่าง 95% CI ของส่วนต่าง ≤ 0) ถ้าผ่านหลายตัว เลือกตัวที่ primary ดีที่สุด ถ้าไม่มีตัวผ่าน = ไม่เปลี่ยน
- **ผ่าน holdout:** ส่วนต่างของ primary เทียบ M0 มีขอบบน 95% CI < 0
- **ถ้วยยุโรป:** primary = log loss 1X2 เทียบผลจริง guard = Brier 1X2 กฎเดียวกัน
- การเทียบตลาดใช้รายงานผล ไม่ใช่เกณฑ์ผ่าน การ "ดีกว่า M0" ไม่ได้แปลว่า "ดีกว่าตลาด"

## ตัวชี้วัดที่รายงาน

| ตัวชี้วัด | วิธีคำนวณ |
| --- | --- |
| Brier, log loss | AH และ O/U 2.5: บน fair target ถ่วงน้ำหนัก; 1X2: Brier สามทาง และ log loss ของผลที่เกิด |
| ส่วนต่าง | paired บนแมตช์เดียวกัน 95% CI แบบ cluster ตามวันฟุตบอล (CR1) เพราะแมตช์วันเดียวกันไม่อิสระต่อกัน |
| Calibration slope | logistic regression y ~ a + b·logit(p) บน 1X2 ที่ซ้อนสามผล (IRLS) b = 1 สอดคล้อง, b > 1 แบนเกิน, b < 1 สุดโต่งเกิน CI จาก bootstrap ตามวัน 200 รอบ seed คงที่ |
| Sharpness เทียบตลาด | ความชันของ logit(p โมเดล) บน logit(p ตลาด) 1 = คมเท่าตลาด |
| ECE | 10 bin ความกว้างเท่ากัน Σ (n_b/N)·\|mean p − ที่เกิดจริง\| บน 1X2 ซ้อนสามผล |
| Underdog | ฝั่งที่ได้แต้มต่อ (AH 0 ใช้ฝั่งที่ 1X2 ตลาดให้ต่ำกว่า) ค่าเฉลี่ยโมเดล ตลาด fair hit และ lean = โมเดล − ตลาด |
| แยกกลุ่ม | ระยะเส้น AH (0, 0.25–0.75, 1–1.5, 1.75+), จำนวนแมตช์ถ่วงน้ำหนักของทีมที่ข้อมูลน้อยกว่า (< 10, 10–20, 20–40, ≥ 40), ลีก, phase early/close |
| O/U 2.5 | รายงานแยก ไม่รวมกับความเอียงของ AH |

## สิ่งที่ทำไม่ได้หรือไม่ทำ

- **รวมข้อมูลหลายลีกในประเทศเป็นโมเดลเดียว:** ทีมแต่ละทีมเล่นในลีกเดียว ยกเว้นทีมขึ้นชั้น/ตกชั้นกับถ้วยยุโรป จึงไม่มีข้อมูลเชื่อมระดับลีกนอกจากถ้วย M3 คือการทดลองเรื่องนี้ในจุดที่ข้อมูลรองรับ
- **ถ้วยยุโรปเทียบตลาดย้อนหลัง:** ไม่มีราคา ใช้ได้เฉพาะ 108 นัดของ `market_closing`
- **Player Impact, Elo และ ensemble:** ไม่อยู่ในขอบเขต เพราะ AH มาจาก DC sides โดยตรง
- **Calibration layer:** ผลทดลอง 2026-10-26 (`docs/audit-remediation-plan.md`) พบว่า temperature บน AH ดันโมเดลเข้าหา 50/50 และ blend เลือกน้ำหนักโมเดล 0 จึงไม่ทำซ้ำในรอบนี้ จะพิจารณาใหม่ถ้า M1–M4 ให้โมเดลที่มีข้อมูลเกินตลาด
